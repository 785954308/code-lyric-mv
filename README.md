# code-lyric-mv

Cursor / Agent **Skill** for making an **original** vertical code-driven lyric MV (canvas/WebGL plates + word karaoke + beat cuts).

Learn craft patterns from open-source references. **Do not copy** another project's story, lyrics, characters, or scenes.

## Install

### Cursor Marketplace (after listing)
Search for `code-lyric-mv` in Cursor Marketplace, or install from this GitHub repo once published.

### From GitHub
1. Cursor → Customize → Plugins → import from GitHub (repo with `.cursor-plugin/plugin.json`)
2. Or clone and point your agent at `skills/code-lyric-mv/SKILL.md`

## What you get
- A reusable pipeline: brief → music → lyrics JSON → treatment → Opus prompt pack → render → accept
- Hard rules against IP copying and README-only "study"
